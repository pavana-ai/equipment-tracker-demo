# Vessel Equipment Tracker — Demo

A clickable demo of an offline-capable equipment tracking app for a fleet of survey vessels:
multiple vessels with a fleet view, QR labels, scan-to-add, supplies stock levels, hard-drive custody,
certificates and calibrations with email reminder rules, CSV/Excel import with checks, outgoing manifests,
fault reports, transmittals and an auto-filed document library.

**Open the demo:** https://pavana-ai.github.io/equipment-tracker-demo/

All data in this demo is **made up** (fictional vessel, company and clients).
Changes you make are saved only in your own browser. Use "Reset demo data" at the bottom to start over.
